# Test Website

A vibe coded test site for a Digital Humanities Course.

**Live site:** https://w5w3.github.io/Test-Website/

A one-page website about *The Mysterious Case of Rudolf Diesel* by Douglas Brunt. It has a short summary, three reasons I recommend the book, a favorite quotation, and a personal anecdote. Everything (HTML and CSS) is in a single `index.html` file, and the layout works on phones.

You can also open `index.html` in any browser to view it locally.
